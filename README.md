# Portfolio – Werner Mitterer-Kling

Persönliche Portfolio-Webseite (Deutsch/Englisch) im Design „Nachtblau“.

## Inhalt
- `index.html` – die komplette Seite (HTML, CSS und JavaScript in einer Datei)

## Lokal ansehen
`index.html` im Browser öffnen, oder in VS Code mit der Erweiterung „Live Server“ starten.

## Online stellen (GitHub Pages, kostenlos)
1. Repo auf **Public** stellen (GitHub Pages ist für private Repos nur mit bezahltem Plan verfügbar).
2. **Settings → Pages → Branch: `main` / `(root)` → Save**.
3. Nach ca. einer Minute ist die Seite unter `https://wernermittererkling.github.io/portfolio/` erreichbar.

Hinweis: Für eine eigene Domain in Österreich wird ein Impressum benötigt.
